Set up your CoreBAR

Do steps 1–3 on the CoreBAR touchscreen. Keep your PC and CoreBAR on the same local network.

  1. Open Android settings

    Swipe down from the top of the CoreBAR screen. Press and hold the gear icon until Android settings opens.

    Use a long press, not a quick tap.

  2. Find ADB WiFi

    Open System → Advanced → Developer options. Scroll down to the Debugging section and find ADB WiFi.

  3. Turn ADB WiFi on

    Enable ADB WiFi. Leave it enabled while using Studio. If the screen shows an IP address and port, you can use those for a manual connection.

  4. Find your CoreBAR in Studio

    Back on your PC, click Find devices, then select the CoreBAR that appears. Studio finds its IP address automatically.

    The default ADB port is 5555. If CoreBAR shows a different port, enter its IP and port manually, for example 10.10.0.181:5555, then click Connect.

Device found, but it will not connect?

Finding CoreBAR and connecting through ADB are separate steps. A device can appear in search results even when WiFi ADB is off.

  • Check that WiFi ADB is enabled on CoreBAR.
  • If it is already enabled, switch it off and on again, especially after a CoreBAR restart.
  • Run Find devices again if the IP address has changed.
  • If no device appears, check that both devices are on the same local network. You can also enter the address manually.
