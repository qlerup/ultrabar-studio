🟣 **UltraBar Studio — ready for community testing!**

I've been working on **UltraBar Studio**, an independent Windows companion for **UltraBar X / CoreBAR**, and it's now ready for people to try out.

Here's what you can do:

🧩 **Build your Core layout** — drag widgets onto the bar, rearrange them, edit each block's settings and deploy to Core.
🎨 **Make it yours** — customize names, colors and supported widget options, including clock/date, PC hardware monitoring and drive usage.
🔌 **Manage your connection** — discover Core on your network, follow module status and access an in-app setup guide.
📦 **Browse the App & Plugin Store** — install approved packages and update them individually, without updating Studio for every supported package release.
🛠️ **Test your own packages** — use *Install from folder* to try local widgets, presets or prebuilt Core APKs before submitting them to the Store.
🔗 **Reach the right developer** — Store cards link directly to each app's own GitHub repository, issues and pull requests.

Studio is **still actively under development**, so this is a testing release rather than a finished product. Bug reports, feedback and suggestions are very welcome!

Current Core integration targets **CB01 / LineOS 1.0.8–1.0.9 with root-enabled WiFi ADB**. The app includes a setup guide to help you get started.
